Задача
Работу над проектом начнём с малого. Реализуем приложение с интерфейсом для командной строки. Это приложение выполняет задачу для поддержания общей инфраструктуры. Оно поможет генерировать тестовые данные, а затем импортировать их в базу данных.

Написание приложения позволит обкатать на практике многие кейсы, которые возникают перед фулстек-разработчиком: чтение файлов на сервере, взаимодействие с внешними сервисами и запись информации в файлы.

+1. Ознакомьтесь с техническим заданием к выбранному проекту, чтобы понимать общую суть разрабатываемого приложения.

+2. Создайте директорию mocks, а в ней тестовый файл в формате tsv. Добавьте в него данные для создания двух предложений об аренде (без комментариев). Данные можете придумать любые. Структура приведена в техническом задании. В следующем задании мы автоматизируем этот процесс.

+3. Подготовьте описание типов для сущностей (опирайтесь на техническое задание проекта). Типы потребуются при реализации импорта данных.

+4. Реализуйте приложение с CLI интерфейсом. Приложение должно поддерживать следующие команды:

--help — выводит информацию о списке поддерживаемых команд. Полный список команд доступен в техническом задании к проекту. Эта команда используется по умолчанию (если пользователь не ввёл никакого параметра).
--version — выводит информации о версии приложения. Версия приложения считывается из файла package.json.
--import — импортирует данные из *.tsv-файла. Результат работы команды import должен выводиться в консоль. 

+5. Добавьте корректный shebang для сценария, который реализует cli.

+6. Протестируйте приложение: проверьте все команды.

+7. Раскрасьте вывод информации в консоли (то, что выводит ваше приложение). Для этого установите в основные зависимости пакет chalk. Оформление остаётся на усмотрение студента.

Обратите внимание, если вы решили использовать модули CommonJS, то устанавливайте четвёртую версию пакета Chalk. В демо-проекте используются ES-модули.
