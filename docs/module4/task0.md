4.9. Установка MongoDB

Задача
Для продолжения разработки приложения потребуется база данных. С её помощью мы решим задачу долгосрочного хранения данных. Существует огромное количество баз данных. Для нашего проекта мы воспользуемся документоориентированной базой данных — MongoDB.

Фактически база данных — это набор из одного или нескольких файлов. В них данные хранятся особым образом. Это позволяет быстро извлекать и записывать новые порции данных.

Задачи записи, извлечения выполняет отдельное приложение — СУБД (Система управления базами данных). В этом задании вам потребуется установить в своей системе такое приложение.

Установить MongoDB можно несколькими способами. Самый простой: загрузить дистрибутив для своей операционной системы с официальной страницы. Установка мало чем отличается от установки любой другой программы.

Другой вариант — воспользоваться Docker. Этот способ немного сложней, но в долгосрочной перспективе он удобней. Загрузка и запуск контейнеров с нужным софтом происходят быстро и ничего не добавляют в систему.

Для работы на курсе подойдут оба варианта. Вы можете выбрать любой.

1. Загрузите и установите последнюю версию MongoDB для своей операционной системы с официального сайта.
Вы можете загрузить полный дистрибутив MongoDB или загрузить соответствующий контейнер для Docker. Дальнейшие пункты объясняют последовательность действий для установки MongoDB в Docker.

2. Этот пункт актуален для тех, кто решил воспользоваться Docker. Установите Docker для своей операционной системы. Инструкции по установке доступны в официальной документации: Windows, linux и macOS.

3. Этот пункт актуален для тех, кто решил воспользоваться Docker. Создайте в корне проекта файл docker-compose.yml и напишите в нём конфигурацию для запуска контейнера с MongoDB:

version: "3.9"
services:
  db:
    image: mongo:4.2
    restart: always
    container_name: six-cities_mongodb
    environment:
      MONGO_INITDB_ROOT_USERNAME: admin
      MONGO_INITDB_ROOT_PASSWORD: test
    ports:
      - 27017:27017
    volumes:
      - six-cities_data:/data/db

  db_ui:
    image: mongo-express:latest
    restart: always
    container_name: six-cities_mongo_express
    ports:
      - 8081:8081
    environment:
      ME_CONFIG_MONGODB_ADMINUSERNAME: admin
      ME_CONFIG_MONGODB_ADMINPASSWORD: test
      ME_CONFIG_MONGODB_URL: mongodb://admin:test@db:27017/

volumes:
  six-cities_data:


        
        
      
4. Этот пункт актуален для тех, кто решил воспользоваться Docker. При необходимости поправьте значение переменных MONGO_INITDB_ROOT_USERNAME и MONGO_INITDB_ROOT_PASSWORD. Этими переменными можно задать имя пользователя и пароль для доступа к базе данных. Также проверьте секцию volumes. В ней мы указали в качестве хранилища six-cities_data. Оно определяется в самом конце конфигурационного файла.

5. Этот пункт актуален для тех, кто решил воспользоваться Docker. Для загрузки и запуска контейнера выполните команду docker compose up -d в директории проекта. Для дальнейшего управления контейнером используйте приложение Docker Desktop (доступно для загрузки с официального сайта).
