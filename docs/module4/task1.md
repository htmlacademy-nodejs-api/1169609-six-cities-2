4.10. Покоритель баз данных

Задача
В этом задании мы подготовим всё необходимое для работы с базой данных и завершим разработку CLI. Напомним, мы реализовали все сценарии CLI, но команда --import пока работает впустую. Она умеет обрабатывать и разбирать TSV-файлы, но с импортированными данными ничего не происходит. Сегодня мы научимся сохранять их в базу данных.

Перед выполнением этого задания убедитесь, что MongoDB корректно установлен и запущен. Вам также пригодится приложение Compass для просмотра данных в MongoDB или mongo-express. Обязательно установите его.

+1. Загрузите клиент для просмотра структуры базы данных (Compass или mongo-express). С помощью этого приложения вы сможете подключиться с СУБД MongoDB и выполнять стандартные операции: просматривать документы, добавлять новые, редактировать и так далее.

+2. Установите пакеты mongoose, @typegoose/typegoose (пакет опционален, можно использовать один mongoose).

+3. Напишите код для установки соединения с базой данных. Факт попытки и установки соединения должен отражаться в логах.

4. Создайте модули и опишите схемы всех сущностей (кроме «Комментарий») для своего проекта. Список сущностей приведён в техническом задании. Обратите внимание, для каждой сущности должна использоваться отдельная коллекция. Валидаторы на данном этапе добавлять необязательно. Помимо полей, перечисленных в техническом задании, всем сущностям потребуются служебные поля: createdAt и updatedAt.

5. Опишите и реализуйте интерфейсы для выполнения операций с базой данных. Список действий: поиск документа, создание нового документа. Для сервиса по работе с пользователями предусмотрите поиск по идентификатору и email пользователя.

6. Обновите конфигурацию контейнера с зависимостями. Добавьте модели и сервисы для работы с базой данных.

7. Доработайте команду --import. Аргументами команда должна принимать настройки для подключения к базе данных. Вы можете использовать как один аргумент и передавать полный путь, так и несколько. Добавьте сохранение данных в MongoDB. Вместо вывода считанных данных в терминал, сохраните их в базу данных.
