Задача

Пришло время частично имплементировать спецификацию, созданную в предыдущем задании, а заодно подготовить проект к дальнейшей разработке. В этом задании мы реализуем приём входящих подключений от клиентов, потренируемся в создании контроллеров, обработке ошибок и обработке запросов от клиентов.

+1. Установите в проект дополнительные пакеты:
+http-status-codes. Пакет предоставляет перечисление со всеми HTTP-кодами.
+express, @types/express. Фреймворк Express и декларации типов.
+class-transformer. Пакет поможет конвертировать объекты в DTO.
+express-async-handler. Для обработки ошибок в асинхронных обработчиках.
Все перечисленные пакеты устанавливаются в виде основных зависимостей, кроме типов для Express.

+2. Доработайте главный класс приложения (Application). Создайте экземпляр Express-приложения и в методе инициализации выполните запуск Express-сервера. Сервер должен запускаться на порту, который указан в конфигурации (переменная окружения PORT).

3. Спроектируйте все необходимые интерфейсы (маршруты, контроллер) и имплементируйте абстрактный класс +Controller. Он будет являться основой для контроллеров каждого ресурса. +В абстрактном классе имплементируйте методы, к которым придётся прибегать для обработки запросов клиентов. Например:

- Успешный ответ (код 200);
- Ресурс создан (код 201);
- и так далее.

+4. Реализуйте в классе Application метод для регистрации middleware. Напишите код для регистрации middleware express.json(). Она поможет распарсить тело запроса в формате JSON.

5. Создайте контроллеры для всех ресурсов, которые вы определили в спецификации за исключением комментариев. Напишите обработчики всех маршрутов. Если обработчик принимает данные от клиента в теле запроса, он всегда ориентируется на DTO. Данные ответа соответствуют форме объекта ответа (Response Object). Обратите внимание, валидацию данных делать не нужно. С этой задачей разберёмся в седьмом разделе.

6. Реализуйте фильтр исключений (Exception Filter). Разделите ошибки сервера и ошибки, возникающие при выполнении HTTP-запросов. Настройте логирование перехваченных исключений. Зарегистрируйте фильтр исключений в Express.

7. Добавьте поддержку перехвата ошибок в асинхронных обработчиках.
