5.8. Спецификация для API

Задача
В этом модуле вы потренируетесь создавать спецификации API. Хорошо продуманная спецификация упрощает реализацию. Первые наброски спецификации для API следует делать на листе бумаге, а когда выстроится базовая структура, её можно перенести в более удобный формат — Open API.

+1. Перечитайте техническое задание к своему проекту. Особое внимание уделите разделам «Сущности» и «Список ресурсов». Информация из них потребуется для подготовки спецификации.

2. Установите в VSCode расширения для работы с OpenAPI: ???openapi-lint и +OpenAPI (Swagger) Editor.

Первое расширение решает задачу линтинга (ESLint для OpenAPI). Оно подсветит опечатки в директивах или наоборот отсутствие обязательной директивы. Второе расширяет возможности редактора и добавляет функцию Preview. Она упростит чтение спецификации.

+3. Создайте в корне проекта директорию specification, а в ней одноимённый файл — specification.yml.

4. В этом файле опишите спецификацию REST API в формате OpenAPI для своего проекта. При составлении спецификации ориентируйтесь на разделы технического задания «Список ресурсов» и «Сущности».

Для предварительного просмотра используйте возможности расширения «OpenAPI (Swagger) Editor».
