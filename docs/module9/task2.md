9.8. Фронтенд + Бэкенд =?

Задача

В последнем задании потренируемся в интеграции фронтенда с бэкендом. Фронтенд готов, остаётся только соединить всё вместе.

Это необязательное задание. Его необязательно выполнять для защиты по базовым критериям. Выполните это задание, если работа над остальной частью проекта завершена полностью.

1. Склонируйте репозиторий с готовым фронтендом для проекта «Шесть городов».

2. Внесите изменения во фронтенд и реализуйте следующие сценарии (обновите структуры данных):

- Регистрация пользователя;
- Вход пользователя в закрытую часть приложения;
- Проверка состояния пользователя (проверка токена);
- Вывод списка предложений на главной странице;
- Добавление нового предложения;
- Просмотр карточки предложения;
- Добавление комментария.
Это обязательные сценарии. Реализация остальных остаётся на ваше усмотрение.

3. Создайте в корне проекта директорию frontend и разместите в ней изменённую версию фронтенда. При необходимости добавьте исключения для линтера (линтер не должен проверять код).
