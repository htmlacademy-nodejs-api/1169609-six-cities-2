9.5. Финальный отсчёт

Задача

В этом задании мы закончим разработку REST API сервиса. Задание заключается в доведении проекта до соответствия техническому заданию за исключением интеграции с фронтендом.

+1. Внимательно перечитайте техническое задание для своего проекта. Реализуйте все пункты за исключением интеграции с фронтендом. Это мы сделаем в следующем домашнем задании.

+2. Установите пакет cors в качестве основных зависимостей. Зарегистрируйте в качестве middleware глобально.

+3. Перепроверьте маршруты в приложении. Добавьте ограничения на ресурсы, к которым могут иметь доступ только авторизованные клиенты.
