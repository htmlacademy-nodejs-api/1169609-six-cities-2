8.11. Посторонним вход запрещён

Задача
В этом задании мы потренируемся создавать приватные ресурсы и разберёмся как реализовать в приложении авторизацию. Решить вопрос авторизации можно разными способами. Вы можете выбрать сессии или JWT. Выбор остаётся на ваше усмотрение.

+1. Реализуйте в приложении авторизацию. Вы можете воспользоваться сессиями или JWT (пакет jose).

+2. Обновите ресурсы API, в которых требовалось передавать идентификатор пользователя. Клиент не должен передавать свой идентификатор. Вместо этого он передаёт токен, по которому идентификатор клиента определяется на стороне сервера.

+3. Обновите сценарии получения списка предложений по аренде. Флаг «Избранное» формируется с учётом нахождения объявления в списке «Избранное» для текущего пользователя. Если запрос на получение списка предложений делает неавторизованный клиент, то значения флага всегда false.

+4. Разработайте middleware для ограничения доступа к закрытым маршрутам.

5. Подключите middleware из предыдущего шага к обработчикам маршрутов, которые доступны только для авторизованных клиентов.

6. Реализуйте сценарий «Выход из закрытой части приложения» (если вы используете сессии).
